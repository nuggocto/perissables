# Les Périssables ༼⁠ ⁠つ⁠ ⁠◕⁠‿⁠◕⁠ ⁠༽⁠つ

A stupid, funny, multiplayer tabletop-style RPG about supermarket food trying
not to die. Two to four friends pick premade characters, explore a grocery store,
and survive dice checks and turn-based combat together.

This is a digital adaptation of a game we already play with friends.
The digital version is in planning. See [PROJECT.md](PROJECT.md) for the rules and release plan.
