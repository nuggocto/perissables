# Les Périssables ༼⁠ ⁠つ⁠ ⁠◕⁠‿⁠◕⁠ ⁠༽⁠つ

A stupid, fun, multiplayer tabletop RPG where players pick premade food characters,
run story-driven adventures, and survive dice/combat events together.

The repository slug is `perissables`; Rust packages use the
`les-perissables-` prefix.

## Documentation

Start with [the documentation index](docs/README.md) for the reading order.
Product and compatibility requirements live in
[the MVP contract](docs/mvp-contract.md); measured implementation decisions are
locked only after their named evidence gate.
